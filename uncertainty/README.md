# Uncertainty Estimation & Explainability (NICE-TO-HAVE)

Tools for quantifying prediction confidence and visualizing model decisions.

## Planned Approach

- **Monte Carlo Dropout:** Run multiple stochastic forward passes at inference time to estimate prediction uncertainty
- **Calibration Error:** Measure expected calibration error (ECE) to assess how well predicted probabilities match actual accuracy
- **Spectrogram Saliency Maps:** Visualize which time-frequency regions of the input spectrogram drive the model's genre prediction
