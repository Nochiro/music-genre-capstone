# Full-Stack Deployment (NICE-TO-HAVE)

End-to-end serving infrastructure for the music genre classifier.

## Planned Approach

- **Backend:** FastAPI server exposing a prediction endpoint
- **Frontend:** React UI for uploading audio files
- **Workflow:** Upload audio → extract features → predict genre + confidence → display results
- **Packaging:** Dockerized for deployment on a cloud VM
